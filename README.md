# Hardware Test Automation

A Python-based hardware test automation and validation project for a simulated 12V power module. The project explores automated electrical measurements, load sweeps, threshold analysis, failure diagnosis, and test reporting.

## Project Features

- Automated DUT (Device Under Test) validation
- Simulated power supply and DUT models
- Configurable test parameters using YAML
- Voltage, current, and power limit checks
- Load sweep and fine-sweep analysis
- Threshold search and failure analysis
- CSV-based measurement and test-result logging
- Python-generated validation reports and graphs
- Pytest-based automated test suite
- PyVISA interface for optional real-instrument communication

## Technologies

- Python
- pytest
- PyVISA
- YAML
- CSV
- Matplotlib

## Project Structure

- `automated_test.py` — Main automated test workflow
- `simulated_power_supply.py` — Simulated power supply
- `dut_model.py` — Simulated device under test
- `test_config.yaml` — Test configuration and limits
- `failure_analysis.py` — Failure analysis
- `threshold_search.py` — Threshold search
- `fine_sweep.py` — Fine load sweep
- `validate_results.py` — Result validation
- `final_validation_report.py` — Validation report generation
- `test_*.py` — Automated tests
- `*.csv` — Recorded test and analysis results
- `*.png` — Generated graphs

## Run the Tests

Activate your Python virtual environment, install the required dependencies, and run:

```bash
python -m pytest -q
```

The real-instrument identification test requires a correctly configured VISA resource and compatible hardware. It is skipped when the placeholder resource name is used.

## Important Note

The simulated test results are generated by software models. They do not, by themselves, demonstrate measurements from physical hardware. Real-instrument validation requires compatible equipment, correct VISA configuration, and appropriate electrical safety precautions.

## Purpose

This project demonstrates practical work in electronics test automation, electrical validation, measurement logging, threshold analysis, and hardware failure investigation.
